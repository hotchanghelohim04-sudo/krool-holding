# Contenus éditoriaux

Ce dossier centralise les **contenus provisoires** du site et de l'Académie
(services, études de cas, équipe, FAQ, articles, modules de formation).

- Chaque contenu existe en `fr` et `en`.
- Tout contenu provisoire porte la mention `TODO-CONTENU` : Lembe le remplacera
  au fur et à mesure (puis depuis le back-office, étape 2).
- Les **libellés d'interface** (boutons, menus, messages) ne sont pas ici :
  ils sont dans `frontend/messages/{fr,en}.json`.

Structure prévue (remplie à partir de l'étape 1) :

```
content/
  services/      une fiche par service
  case-studies/  3 études de cas fictives (marquées « exemple »)
  team/          équipe provisoire
  faq/
  blog/          3 articles
  academy/       5 modules de lancement (étape 4)
```
